# যোগীপাল সমাজকল্যাণ ফাউন্ডেশন — ওয়েবসাইট

Next.js স্ট্যাটিক সাইট। GitHub Pages-এ অটো ডিপ্লয় হয়।

## GitHub-এ হোস্ট করার ধাপ
1. নতুন repository বানিয়ে সব ফাইল `main` branch-এ push করুন।
2. Repository → Settings → Pages → Source: **GitHub Actions** বেছে নিন।
3. Push করলেই সাইট বিল্ড হয়ে `https://USERNAME.github.io/REPO/` লিংকে চালু হবে।

## লোকালে চালানো
pnpm install
pnpm dev
